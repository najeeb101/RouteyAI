05 How it works

Addresses in. Routes out.

  1. 01

    Add students

    Each home address is found and pinned on the map.

  2. 02

    Group by area

    Nearby homes are grouped, and no bus gets more students than it has seats.

  3. 03

    Order the stops

    Stops go in the shortest order, using real road travel times.

  4. 04

    Run the route

    Drivers start, parents follow, and a new student joins the nearest bus with a free seat.
